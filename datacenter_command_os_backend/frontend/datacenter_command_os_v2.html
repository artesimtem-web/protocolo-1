Asistente de planificación

Esta primera versión usa reglas locales explicables, no un modelo de IA conectado. Genera observaciones a partir de los datos que hayas registrado; revisa y valida cada sugerencia antes de actuar.

Selecciona “Analizar infraestructura” para revisar capacidad eléctrica declarada, datos incompletos y reservas.

Las sugerencias no ejecutan cambios. Los cambios en las tablas se guardan localmente en este navegador. No hay conexión a hardware ni base de datos central en esta versión.
